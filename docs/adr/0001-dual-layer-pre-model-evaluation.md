# 0001 前置评估采用双层架构：L1 快筛 + L2 增量

单特征统计指标（IV/KS/单特征 AUC/Lift）只能回答"特征自身有没有区分度"，回答不了"加入后模型是否变好"——大量特征单看有效但与已有特征冗余；而对全量候选逐一做模型消融在 Spark 上的算力开销不可接受。因此前置评估固定为两层：L1 纯统计快筛确定数据准入与候选优先级（v0.4 由 ADR-0007 更新，不预设过滤比例），L2 轻量代理模型消融（+残差分析，若可获取基线模型分数）给出最终增量结论；评估报告必须同时呈现两层结果。

## Considered Options

- 仅 L1：漏掉冗余特征与交互价值，结论不可信。
- 仅 L2：全量候选逐一消融，算力不可行。
- 双层（选定）。

## Consequences

- 工具与报告结构天然分为两层，L2 按 L1 优先/常规队列执行，并保留交互专项与随机审计通道；数据 blocked 或 review 时先修复/核实。弱 AUC/IV 或不显著 Bias 不直接拒绝候选。
- L2 结论必须标注代理模型与线上精排模型的结构差异带来的偏差。


## v0.4 补充（2026-11-11）

L1 的存量分桶 Bias/平均残差不训练；L2 的残差增量需要训练。流程与路由由 [ADR-0007](0007-l1-evidence-and-routing.md) 定义；统计阈值待校准，原型仍未对齐。
