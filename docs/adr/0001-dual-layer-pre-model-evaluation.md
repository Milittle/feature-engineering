# 0001 前置评估采用双层架构：L1 快筛 + L2 增量

单特征统计指标（IV/KS/单特征 AUC/Lift）只能回答"特征自身有没有区分度"，回答不了"加入后模型是否变好"——大量特征单看有效但与已有特征冗余；而对全量候选逐一做模型消融在 Spark 上的算力开销不可接受。因此前置评估固定为两层：L1 纯统计快筛过滤大部分候选，L2 轻量代理模型消融（+残差分析，若可获取基线模型分数）给出最终增量结论；评估报告必须同时呈现两层结果。

## Considered Options

- 仅 L1：漏掉冗余特征与交互价值，结论不可信。
- 仅 L2：全量候选逐一消融，算力不可行。
- 双层（选定）。

## Consequences

- 工具与报告结构天然分为两层，L2 只对 L1 通过的候选执行。
- L2 结论必须标注代理模型与线上精排模型的结构差异带来的偏差。
