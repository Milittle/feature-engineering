# 0004 入模判据用优效检验，下线判据用非劣效检验

入模和下线的举证责任方向相反：特征入模要付存储、计算、在线延迟和维护成本，必须证明"有增益"（L2 主指标 Δ 的 CI 下界 > δ_min）；特征下线只需证明"去掉不变差"（去特征 Δ 的 CI 下界 > −ε）。v0.1 对入模也用了非劣效判据（Δ ≥ 0 且 CI 下界 > −ε），真实增量为 0 的冗余特征只要点估计碰巧 ≥ 0 就能通过，与 ADR-0001 设 L2 拦截冗余特征的目的相抵。

## Considered Options

- 两侧都用非劣效（v0.1）：冗余特征持续入模，特征集只增不减。
- 两侧都用优效：下线需证明"去掉后变好"，几乎无法满足，同样只增不减。
- 入模优效、下线非劣效（选定）。

## Consequences

- 只有深度模型能利用、代理模型看不出的增益（如高基数 ID 交互）会被保守拒绝，这类特征要靠残差分析或线上实验补证。
- δ_min 与 ε 不能拍定，须用对照特征做评估器校准（方案 7.1）。
- 多代理时同样不对称：入模取任一代理优效，下线要求全部代理非劣效（方案 3.2.1、5.4）。
- v0.3 补充（方案 5.4、ADR-0006）：
  - 非劣效边界 Δ_NI ≤ δ_min，否则同一特征可能「入模要求的增益」小于「下线容忍的损失」，反复进出；
  - 非劣效以**特征组**为单位判定：单独去掉任一个都不掉点、同时去掉才掉点的冗余组，逐个判定会一起漏下线；
  - 跨批设累计预算：每季度固定锚点模型，每批下线后相对锚点的 Δ 下界须 > −ε_cum，防止多批「各自非劣、累计劣化」。
  - 公开推荐系统文献中没有使用「非劣效」或「累计预算」术语的下线案例，这两个概念借自临床试验惯例；最接近的工程先例是 SHARK 相对原始基线的累计精度阈值与 Meta IEFF 的渐隐下线。
