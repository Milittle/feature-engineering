# 0003 公司基础设施依赖全部经适配器隔离

Spark 作业提交 API、调度系统、特征元数据系统、模型 importance 回传与线上打分回放均属公司内部基础设施：选型未定（调度、物理架构明确推迟讨论）或接口细节不由本团队掌控（提交 API 由使用方自行补齐）。决定：逻辑架构中以上依赖一律通过六类适配器（作业提交 / 调度 / 元数据 / importance 回传 / 线上打分 / 报告分发）隔离，评估引擎与编排模块只依赖契约，不依赖具体实现；各适配器实现推迟到对应分期落地。

## Consequences

- 方案评审与详细设计不被基础设施细节阻塞；任一依赖的内部变化不扩散到引擎层。
- 适配器契约定稿即冻结（本文档第 6 章为 v0.1 契约），修改契约需走 ADR。
