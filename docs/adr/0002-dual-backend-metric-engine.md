# 0002 评估计算引擎：Spark 批算核 + 本地分析模块双后端

评估数据在 Hive，生产规模（100w/1000w 行，可配置）的指标计算必须提交到公司 Spark 平台；但报告聚合、阈值判定、渲染等分析步骤是本地轻量计算。决定：指标计算层设计为双后端——Spark 后端（生产规模）与本地后端（Polars，采样数据，供调研、调试与小样本分析），共享统一的指标定义接口；样本量与执行后端通过配置切换。

## Consequences

- 每个指标在两个后端必须口径一致，用同一份数据互校。
- 集群提交方式（spark-submit/平台 API 等）是待定事实，锁定后另立 ADR。


## v0.4 聚合契约扩展（2026-11-11，ADR-0007）

旧 `(bin,pos,neg)` 接口仅覆盖部分描述指标。L1 存量预测分 Bias 需要相同有效样本集合的权重和、实际/预期转化量；聚类 CI 还需要用户×桶×时间片级统计或后端生成的同口径重采样结果。两后端必须互校这些统计及随机权重，不能由桶总计数推断用户内相关性。此为方案契约，原型待实现。
