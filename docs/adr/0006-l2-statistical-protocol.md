# 0006 L2 统计协议：ΔLogLoss 检验量、总方差、四分区判定、经验校准（提议，v0.3 评审中）

v0.2 的 L2 用 ΔAUC 的聚类 bootstrap CI 做三分判定，有四个缺口：嵌套模型上基于 ΔAUC 的检验过于保守（Pepe 2013）；CI 只含评估端抽样方差，漏掉训练样本的抽样方差（原型中换种子几乎不产生方差）；「无显著增量」直接拒绝，弱增量特征成批误杀（R4）；双代理取并与批量候选都没有多重比较控制，负对照只用来事后核对。决定：检验量用逐样本配对 ΔLogLoss，ΔAUC 作效应量；SE² = V_eval + s²_train/R，评估端与训练端都用按分组键哈希播种的 Poisson 权重；按负对照拟合的经验零分布 N(μ̂, σ̂² + SE²) 计算 p 值，双代理 p 值 Bonferroni 合并后做批内 BH；判定分优效 / 等效 / 有害 / 功效不足四区，并报告 MDE。v0.2 的规则是 μ̂ = σ̂ = 0、R = 1、单窗口、不做 BH 时的特例。

## Considered Options

- 维持 v0.2：弱增量误杀与多重比较问题无法解决。
- 完整 knockoff 框架：需对全部特征联合分布建模，knockoff+ 还要求至少选出 ⌈1/q⌉ 个特征，不适合逐批少量候选。
- ΔLogLoss + 总方差 + 经验校准 + 四分区（选定）。经验校准借自 OHDSI 的负对照方法，用于 ΔLogLoss/ΔAUC 在机器学习领域没有找到先例。

## Consequences

- 预注册参数（α₁、q、β、B、K、R、δ_min、Δ_eq、Δ_NI、确认日）写入评估器版本，批次开始后不得修改（方案 3.0）。
- 负对照必须与候选同构、按粒度分层，每层足量（L1 199 个、L2 每批 20 个且累计 ≥ 50 个），并做留一自检（方案 3.6）。
- 经验校准会提高第二类错误，用分级正对照的检出率曲线监控。
- 联合确认移到独立的确认日，只做一次（方案 3.2.5）。
- 原型 `feval/` 需按方案 7.4 对齐（V0.5）。
